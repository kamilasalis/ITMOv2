# Quickstart: проверка фичи «Таблица рекордов (UI)»

## Предусловия

- Node 24+, Python с зависимостями `backend/requirements.txt`.
- Эндпоинты `/race-results` и `/leaderboard` есть в `backend/` (фича 002).

## 1. Автоматические проверки

```bash
bash scripts/check.sh            # бэкенд: ruff + pytest → PASS (не меняется этой фичей)
cd frontend && npm test          # фронтенд: node --test tests/ → все тесты зелёные
```

`npm test` в `check.sh` не входит — запускать вручную (решение 2026-10-28).
Что покрыто: [contracts/ui-components.md](contracts/ui-components.md) (чистые функции),
[contracts/api-client.md](contracts/api-client.md) (клиент API).

## 2. Запуск

```bash
cd backend && uvicorn app.main:app --reload --port 8000
cd frontend && npm run dev       # http://localhost:5173
```

Чтобы начать с пустой таблицы — остановить бэкенд и удалить `backend/leaderboard.json`.

## 3. Ручные сценарии (браузер)

| # | Действие | Ожидаемо | Spec |
|---|----------|----------|------|
| 1 | Открыть сайт | Поля «Игрок 1» / «Игрок 2»; таблица: «Пока нет рекордов — станьте первым!» | US1-1, US3-1 |
| 2 | Стереть имя игрока 1, «Начать заезд!» | Гонка не стартует, «Введите имя» | US1-5 |
| 3 | Ввести «Камила» и « камила » | «Имена игроков должны различаться» | US1-7 |
| 4 | Вставить 25 эмодзи | В поле 20, счётчик «20/20» | US1-6 |
| 5 | Ввести «  Камила   Салис  », старт | В поле и HUD — «Камила Салис» | US1-8 |
| 6 | Во время отсчёта | Таймера нет | US2-1 |
| 7 | Гонка | Таймер от «00:00.00», растёт | US2-2 |
| 8 | Финишировать | «Время круга: …», «Сохраняем результат…» → «Результат сохранён ✓», таблица обновлена, строка подсвечена, «Новый рекорд!» | US2-4, US4-1, US4-2, US3-8 |
| 9 | Остановить бэкенд, обновить страницу | «Не удалось загрузить рекорды» + «Повторить»; гонка стартует | US3-5 |
| 10 | Запустить бэкенд, «Повторить» | Таблица загрузилась | US3-6 |
| 11 | Остановить бэкенд, пройти гонку | «Не удалось сохранить результат» + «Повторить»; запустить бэкенд, «Повторить» → «Результат сохранён ✓» | US4-3, US4-4 |
| 12 | Пройти гонку, сразу «Новая игра» | «Выбор» без статуса сохранения; таблица загружается заново | US4-8 |
| 13 | Наполнить > 10 имён (через `curl` POST), затем медленный результат нового имени | Топ-10, ниже «Последняя гонка: место · имя · время» | US3-10 |
| 14 | Скрыть вкладку на 5 с во время гонки | После возврата таймер учёл 5 с | US2-8 |

Наполнение для сценария 13:

```bash
for i in $(seq 1 11); do
  curl -s -X POST localhost:8000/race-results -H 'Content-Type: application/json' \
       -d "{\"name\":\"Бот $i\",\"lap_time_ms\":$((30000 + i*1000))}" >/dev/null
done
```
