# API Contract: таблица рекордов

Серверная часть [../../contract.md](../../contract.md) 2.4–2.5. При расхождении действует общий
контракт. Базовый адрес — `http://localhost:8000` (как у существующих `/select-car`, `/report-error`);
CORS для `http://localhost:5173` уже настроен.

## `POST /race-results`

Сохранить время победителя гонки.

**Запрос** — `application/json`, ≤ 2048 байт, лишние поля запрещены:

```json
{ "name": "Камила", "lap_time_ms": 65400 }
```

| Поле | Тип | Ограничения |
|------|-----|-------------|
| `name` | string | после нормализации (края обрезаны, серии пробельных символов → один пробел) 1–20 кодовых точек |
| `lap_time_ms` | integer | 3000–5 999 999, только целое число JSON |

**Ответ `201 Created`**:

```json
{
  "name": "Камила",
  "lap_time_ms": 65400,
  "best_time_ms": 61230,
  "is_new_record": false,
  "place": 4
}
```

| Поле | Тип | Смысл |
|------|-----|-------|
| `name` | string | Нормализованное имя из запроса |
| `lap_time_ms` | integer | Время этой гонки (эхо) |
| `best_time_ms` | integer | Рекорд имени после записи |
| `is_new_record` | boolean | `true`, если время строго лучше прежнего рекорда или это первый результат имени |
| `place` | integer | Место имени после записи, всегда число |

Повтор того же запроса безопасен: рекорд не меняется, `is_new_record = false`.

## `GET /leaderboard`

**Параметры**: `limit` — integer 1–50, по умолчанию 10.

**Ответ `200 OK`**:

```json
{
  "entries": [
    { "place": 1, "name": "Боря", "best_time_ms": 40000, "achieved_at": "2026-10-28T10:00:00.000000Z" }
  ],
  "total": 14,
  "last_result": {
    "name": "Камила",
    "lap_time_ms": 58730,
    "place": 13,
    "finished_at": "2026-10-28T12:30:00.000000Z"
  }
}
```

- `entries` — по возрастанию `best_time_ms`; при равенстве раньше `achieved_at` → выше; места
  не повторяются.
- `total` — число имён в хранилище.
- `last_result` — последний успешно сохранённый результат (общий для всех клиентов) или `null`;
  `place` — текущее место этого имени по лучшему времени.
- Пустое хранилище: `{"entries": [], "total": 0, "last_result": null}`.

## Ошибки

| Код | Когда | Тело | Хранилище |
|-----|-------|------|-----------|
| 422 | Невалидное тело или `limit` | стандартное тело FastAPI (`{"detail": [...]}`) | не меняется |
| 413 | Тело > 2048 байт | `{"detail": "Запрос слишком большой"}` | не меняется |
| 503 | Файл хранилища не читается, повреждён или не записывается | `{"detail": "Хранилище рекордов недоступно"}` | не меняется; повреждённый файл не перезаписывается |

Реакция клиента на коды — [../../contract.md](../../contract.md) 2.5 (не входит в эту фичу).
