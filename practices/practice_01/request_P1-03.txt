Другие источники и фантазии запрещены.

Цель:
Сгенерировать целостный инженерный контур из 8 связанных SDLC-артефактов без плейсхолдеров и абстрактных рассуждений:
1. analysis.md: AS IS, TO BE (Mermaid flowchart) и таблица разницы.
2. product_management.md: первый рабочий сценарий, Use case с Sequence diagram (Mermaid), 3 Gherkin-сценария.
3. project_management.md: 3 инкремента (разбивка Человек / AI, критерии, проверки) и диаграмма Ганта (Mermaid).
4. adr.md: статус accepted, контекст по diff, 5 пунктов решения, 3 альтернативы с причинами отказа, Mermaid-схема потока данных.
5. tests_unit.md: изолированные проверки санитайзера (SEC-1), валидатора (API-1), парсера (OUT-1, QA-1) с кодом assert.
6. tests_integration.md: стыки FastAPI <-> ReviewService, лимит 413, таймаут 10s (REL-1), проверка caplog на OBS-1.
7. tests_load.md: реалистичные профили нагрузки для MVP, обоснование лимитов с учетом внешнего LLM.
8. tests_e2e.md: сквозные сценарии (позитивный, негативный, граничный) с готовыми CLI/curl-командами.

Ограничения и правила:
- Grounding: использовать только правила из context.md. Запрещено придумывать инфраструктуру, базы данных, авторизацию, если их нет в контексте.
- Границы AI (SCOPE-1): система только анализирует и рекомендует; никакого автомёрджа или изменения кода в GitHub.
- Никаких TODO, TBD, многоточий и общих советов.
- В каждом файле должна быть заполнена секция «Как использовали AI» со ссылкой на строку P1-03 в prompts.md.

Формат вывода:
Выдай итоговое содержимое для каждого из 8 файлов с четкими заголовками `### FILE: <filename>`.
