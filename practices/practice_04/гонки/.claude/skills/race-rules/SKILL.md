# Skill: Race Rules Checker

Этот навык автоматизирует проверку ограничений в проекте «Гонки».

## Правила проекта
1. Допустимые модельки: `racer`, `drifter`, `tank`.
2. Допустимые цвета: пастельная палитра (`red`, `yellow`, `purple`).
3. Валидация входных данных: Pydantic с `extra="forbid"`.
4. Бэкенд тесты обязаны быть зелёными (`pytest`).
5. Фронтенд должен использовать Vue 3 Composition API (`<script setup>`).
