## Бэкенд

- **Источник:** `fastapi/fastapi` (официальный репозиторий FastAPI)

- **Зачем:** основной skill для работы с FastAPI — структура роутов, зависимости (DI),

## Разбор устройства скилла `vue-best-practices` (для ДЗ)

Скилл `vue-best-practices` устроен как набор контекстных инструкций и правил по архитектуре компонентов на Vue 3. Внутри он задаёт использование Composition API через синтаксис `<script setup>`, отказ от Options API и запрет прямого мутирования пропсов. Также он регламентирует разделение логики на composables и строгое типизирование событий через `defineEmits`. При работе над экраном гонки этот скилл позволил агенту сразу написать чистый компонент без бойлерплейта и устаревших паттернов.
