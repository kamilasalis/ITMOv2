# Промпты практики 8

## Запрос на макет и реализацию

> Создай русскоязычный веб-интерфейс «Что готовим?» для человека, который хочет собрать меню из доступных дома продуктов. Основное действие должно вести от реального выбора пользователя до рассчитанного меню. Сохрани интерактивный макет и отдельно представь рабочий интерфейс.
>
> Начни с полноэкранного ролика с жарящимися яйцами. Заголовок и подпись поверх видео белые, фон затемнён только для читаемости. Видео зацикливается без звука, его можно остановить. Ниже сделай отдельные экраны, которые открываются при прокрутке. При переходах используй одну непрозрачную рисованную тарелку, которая вращается и спускается по экрану. В конце показа меню она останавливается в центре, над ней поднимается пар. При включённом сокращении движения убери вращение и оставь ручное воспроизведение видео. Оформи проект в тёплых цветах и с крупными заголовками по мотивам пользовательских референсов Maxima Therapy и Hungry Tiger. Добавляй только элементы, нужные для подбора или просмотра меню.
>
> Первый экран выбора предлагает завтрак, обед, полдник и ужин. Пользователь выбирает от одного до четырёх приёмов. Покажи число выбранных приёмов. Оформи карточки без эмодзи. Для завтрака используй рассвет, для обеда яркое солнце, для полдника уходящее солнце, для ужина поздний вечер со звёздами. Следующий экран показывает каталог продуктов по группам «Белки», «Клетчатка», «Углеводы» и «Жиры». Для продуктов используй единый набор рисованных иллюстраций в стиле кулинарной книги. Добавь поиск по названию. Поиск скрывает несовпадающие строки, но сохраняет выбранные продукты. Последний экран выбора задаёт размер порций. «Дефицит» уменьшает граммовки на 15%, «Норма» оставляет их, «Профицит» увеличивает на 15%. Это масштабирование рецепта. После нажатия «Готовить» покажи до трёх вариантов меню, по одному экрану на вариант. Для каждого блюда выведи приём пищи, название, время, граммовки и раскрываемое приготовление.
>
> Используй реальные данные каталога и алгоритм подбора. Сначала предложи рецепты, для которых совпали все обязательные продукты. Если для приёма нет точных совпадений, покажи ближайшие варианты и перечисли, что нужно добавить. Отдельно обработай пустой ответ источника данных и ошибку. При ошибке сохрани форму и предложи повторить. Не отправляй запрос без выбора хотя бы одного приёма пищи и продукта. Пока запрос выполняется, покажи загрузку и заблокируй повторную отправку кнопкой и Enter.
>
> Переиспользуй готовые компоненты Bootstrap 5: кнопки через `btn`, поиск через `form-control`, карточки результата через `card`. Тему задай общими CSS-переменными. Нативные чекбоксы, радиокнопки и элементы раскрытия должны работать с клавиатуры. Сохрани видимый фокус и проверь узкий экран. Вынеси каталог и подбор в отдельный модуль. Реальный локальный API должен обращаться к этому модулю и возвращать варианты меню. HTML также должен открываться прямо из папки и использовать тот же алгоритм.
>
> Для сдачи сохрани макет, исходники, проектные команды в разделе README, скриншоты состояний, полный вывод тестов и краткое описание изменений после проверки. Указывай, какие шаги демонстрируются на реальных данных, а какие через подмену ответа.

## Запрос на клиентские тесты

> Предложи тесты Playwright на действия пользователя и видимый результат. Один тест должен пройти через реальный API от выбора завтрака, яиц и помидоров до омлета на экране и раскрытия рецепта. Проверь изменение граммовок, обязательный выбор, поиск без результатов, сохранение выбора при смене поиска, клавиатуру, отсутствие точных совпадений и список недостающих ингредиентов. Подмени ответы API для задержки, пустого ответа, ошибки и успешной повторной попытки. Используй тот же формат ответа, что в реальном API. При задержке повтори Enter и событие отправки, затем проверь, что запрос был ровно один. Прогони все тесты и сохрани вывод. Временно отключи сообщение об ошибке, чтобы целевой тест упал. Восстанови интерфейс и снова прогони набор.

## Запрос на иллюстрации

> Создай лист из двадцати рисованных иконок продуктов в сетке 5 × 4. Каждая иллюстрация в своей ячейке и достаточно крупная для карточки. Общий стиль как в кулинарной книге: гуашевые заливки, карандашный контур, тёплая палитра и кремовый фон. Без подписей. В первом ряду яйца, курица, лосось, рис и паста. Во втором овсянка, хлеб, помидоры, огурцы и морковь. В третьем шпинат, картофель, йогурт, яблоко и бананы. В четвёртом авокадо, оливковое масло, сыр, творог и ягоды.
